# 固定资产价值计划 v1

输入as_of_month及1..200个唯一id资产，category非空，cost_cents和salvage_cents为0..10^12整数且残值≤成本；life_months为1..600；in_service_month、可选disposal.month均规范YYYY-MM。disposal只能null或{month,proceeds_cents}，处置不可早于投入月。币值为调用者同一货币的整数分，禁止隐式浮点和布尔值。不生成采购/出售真实凭证，不提供任何地区法定税务会计建议，以下是本仓明确的计算约定。

投入月份即视为整月使用，月内日期不适用；处置月份不计折旧。第i个使用月累计折旧=floor((cost-salvage)*i/life)，当月金额等于累计差额，保证满life月精确到残值，无额外分币丢失。截止月参与折旧，未来投入资产recognized_cost与期末账面为0；其原cost字段仍保留。早于截止的处置以当月前累计计算账面价值并产生proceeds-carrying有符号处置损益，之后不再有资产账面。未来处置不影响当前生命周期；使用期满但未处置仍以残值挂账，状态fully_depreciated。

每资产同时给monthly价值轨迹、累计费用和处置证据，类别汇总共享这些事实而非另套公式。summary累计费用包含已处置资产生前费用，不等于“当前持有资产累计折旧”；处置资产的账面清零单独反映。首次投入即处置允许、折旧0，不能出现负月份。全部成本等于残值也允许，折旧0但仍遵守使用期状态。

输出范围最多200×600个月行，无网络和持久交易状态。无重估、减值、资本化新增、部件拆分、多币种或审计审批。非法输入/已有目标退出2，所有计算完毕后同目录临时文件原子新建报告，不覆盖旧文件。
