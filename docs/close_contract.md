# 固定资产关账流水与可对账月报 v1（asset-close）

本文件是本仓自有的整数分记账约定，不涉及任何外部会计准则。`asset-close` 与
`asset-schedule` 共用同一套整月折旧与处置规则、严格 JSON 输入、8 MB 上限及
“目标已存在即退出 2、原子新建”的发布约定；旧 `asset-schedule` 的输入、输出与
行为保持不变。

## 输入契约

根对象仅含 `first_close_month`、`as_of_month`、`revisions` 三个字段。

- 两个月份均为规范 `YYYY-MM` 字符串；从首个关账月到截止月（含）跨度 1–120 个月。
  期初没有任何历史余额。
- `revisions` 为 0–2400 条修订的数组，顺序不代表先后。每条仅含
  `known_month` 与 `asset`：
  - `asset` 是 `asset-schedule` v1 的完整资产记录，沿用全部字段、校验和单位
    （`id`、`category`、`cost_cents`、`salvage_cents`、`life_months`、
    `in_service_month`、`disposal`），另要求投入月份不早于首个关账月。
  - `known_month` 是财务首次可在该月关账使用这版事实的月份，不得早于首个关账月，
    可以早于或晚于投入、处置月份。
  - 同一资产 ID 在同一 `known_month` 至多一版，重复即非法；不同 ID 总数至多 200。
  - 整条替换而非合并；新版本 `"disposal": null` 即撤销前版出售。
  - 截止月以后才知道的版本也必须完整通过校验，但不影响本次报告。
- 禁止隐式浮点、布尔值、重复 JSON 键、未知字段与非有限常量。

## 经济事实与归属键

对每份关账时可见的资产版本，按 v1 规则重算四类有符号金额：`cost`、
`depreciation`、`carrying_removed`、`proceeds`。

- 投入月记成本；第 i 个使用月折旧为
  `floor((cost-salvage)*i/life) - floor((cost-salvage)*(i-1)/life)`，
  满寿命精确折到残值。
- 处置月不计折旧；以处置前累计折旧算账面价值，当月确认
  `carrying_removed`（转出账面）与 `proceeds`（出售所得）。投入即处置允许，
  此时折旧为零、成本与转出同月确认。使用期满未处置则保留残值。
- 归属键为四元组（经济月、资产 ID、该版本类别、金额种类）。经济月是业务按此
  版本应发生的月份，不是收到版本的月份。修订可改变类别、成本、残值、寿命、
  投入月与出售事实；受影响的全部归属键（含新版本不再存在的键）都必须反映，
  不允许只在类别或全仓合计层面补差。

## 关账流水（journal）

每月先纳入当月所有已知版本，再执行一次关账。

- 一次关账只能发布当月流水，不能重写较早月份已发布的行，也不能为未来经济月
  提前入账；未来版本在其经济月到来前被撤销时，不留下任何流水痕迹。
- 关账后，每个不晚于该关账月的归属键，自首月起已发布的有符号净额必须等于按
  本次关账已知版本计算的应有金额，不存在的键按零处理。
- 同一关账月内同一归属键只发布一条非零净额；净额为零则不发布。旧月更正留在
  收到更正的当月入账、保留原经济月；键迁移须冲销旧键并确认新键，两条分录
  不得相互吞掉。
- 每行字段为 `posted_month, economic_month, asset_id, category, kind,
  amount_cents`，按前五项稳定排序。

## 月报（periods）与对账

`periods` 按月升序覆盖整个关账范围，含无任何发生额的空月份。每项含 `month`
与按类别组织的两种口径：

- `booked`：按 `posted_month` 汇总本月关账流水，即历史上真正发布过的数字，
  旧关账永不改写。
- `restated`：用截止月已知的最终版本按经济月重算，不把补账挪到收到更正的
  月份；只统计经济月落在关账范围内的键。

两种口径中每个类别给出：

- 四类本月有符号净发生额：`cost_cents`、`depreciation_cents`、
  `carrying_removed_cents`、`proceeds_cents`；
- `gain_loss_cents = proceeds_cents - carrying_removed_cents`；
- `closing_book_cents`：自首月累计成本减累计折旧、再减累计账面转出。

某月某口径下四项发生额与期末账面全为零的类别省略；类别按字典序稳定输出。
截至同一截止月，两种口径的累计四项金额与期末账面分别按类别对平（程序内置
对账校验，不平即按失败处理）；历史各月两种口径不必相同。

## 输出与失败约定

报告顶层仅含 `first_close_month`、`as_of_month`、`journal`、`periods`。
非法输入或输出目标已存在时退出码 2 且保留旧目标；全部校验与计算完成后，
通过同目录临时文件原子硬链接新建一份完整 JSON 报告，成功退出 0。
